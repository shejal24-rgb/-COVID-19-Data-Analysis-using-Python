# COVID-19 Data Analysis

This project analyzes COVID-19 data using Python, Pandas, NumPy, and Matplotlib to understand case trends, recoveries, deaths, and active cases over time.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## Dataset

The dataset contains:

* Date
* Country
* Confirmed Cases
* Recovered Cases
* Deaths

Dataset file:

`data/covid19_data.csv`

## Analysis Performed

* Total confirmed cases
* Total recovered cases
* Total deaths
* Active cases
* Recovery rat
